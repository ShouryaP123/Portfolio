# Shourya Patel — Portfolio

Single-page aerospace engineering portfolio, hosted on GitHub Pages.

## Files
- `index.html` — the entire site (HTML + CSS in one file)
- `images/` — all figures
- `.nojekyll` — tells GitHub Pages to serve files as-is

## To host (free)
1. Create a public repo named `<your-username>.github.io`
2. Upload everything in this folder to the repo root
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, Save
4. Wait ~1 minute, then visit `https://<your-username>.github.io`

To update text or numbers later, edit `index.html` and re-upload.
